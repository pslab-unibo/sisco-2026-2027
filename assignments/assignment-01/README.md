# Assignment #01 

v1.0.2-20271005

The assignment is about 
- Modelling a concurrent system, using FSP and Petri Nets.
- Analysing properties specified in FLTL upon the FSP model.

###  Description 

We want to model a concurrent system given by a lift of a building with N floors and its users. At each floor there could be multiple users (up to M) that want to use the lift.  The lift has a capacity of only one user at a time. At each floor users have a button to call the lift. Inside the lift, the user has buttons to select the floor to go. Users getting the lift on some floor should be served in order using a first-come-first-served/FIFO policy.  An alarm signal could be generated by a fire alarm system: in that case, the lift would interrupt current activities, move to the ground floor, open the door and wait, until some external signal about the alarm being solved is received. 

Properties that the system should have:
- Only one user at a time should be using the lift.
- If a user is calling the lift, the lift will eventually arrive (but in alarm case).
- If a user inside the lift select a floor, he/she would finally arrive at the floor (but in the alarm case).
- A user waiting to get the lift on some floor should finally get the lift (but in the alarm case).

### The Assignment

1. Define a model of the concurrent system in FSP.
2. Define a model of the same system using using Petri Nets.
2. Define the properties in FLTL and verify them using the LTSA tool.
